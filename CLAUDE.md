# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project

Personal website for www.jharg.com — personal posts, pricing material, book reviews, etc. Published via GitHub Pages. First piece: DUoS (Distribution Use of System) interactive explorer.

## Stack

**Observable Framework** — static site generator for data journalism. Markdown + reactive JavaScript cells. Builds to `dist/` for GitHub Pages deployment.

- `src/` — all source files (pages, components, data, CSS)
- `src/data/` — JSON data files (generated by `../uk-pricing-model/publish/duos/build_data.py`)
- `src/components/` — reusable JS chart components
- `dist/` — build output (.gitignored)

**Styling:** Blueprint Design System (IBM Plex Mono, cream paper palette). `src/theme.css` overrides Observable Framework variables; `src/blueprint.css` contains all design tokens.

**Deploy:** GitHub Actions → GitHub Pages. Trigger: push to `main`.

## Data pipeline

Data flows one-way from the private `uk-pricing-model` repo:
```
uk-pricing-model/publish/duos/build_data.py  →  jharg.com/src/data/*.json
```
Never edit JSON files in `src/data/` by hand — regenerate via the Python script.

## Dev

npm run build  # builds to dist/
